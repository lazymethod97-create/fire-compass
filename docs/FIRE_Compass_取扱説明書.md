# FIRE Compass 取扱説明書

FIRE Compassは、「今月いくら使っていいか」「どこから取り崩すか」を、資産状況・市場環境・社会保険料や税金の概算まで踏まえて判断するための個人利用アプリです。この説明書は、画面のどこに何を入力し、どんなときにどの機能を使えばよいかをまとめたものです。

---

## 1. 基本の使い方（月1回のルーティン）

月1回アプリを開いたときの、おすすめの流れです。

1. アプリを起動すると、**前回保存した入力値が自動で反映**されています（現在の市場環境だけは、毎回その場で自動判定されます）。
2. 画面上部の「🗂️ 簡易モード」がONの状態では、入力欄や詳細分析は折りたたまれ、**判定結果・推奨行動・実績記録だけ**が表示されます。資産残高が変わっていなければ、このまま次のステップに進んでOKです。
3. 資産残高が変わっている場合は、「📝 入力・資産の確認・編集（1〜3）」を開いて、CSV取り込みまたは手入力で更新します（詳しくは「2. 入力項目」を参照）。
4. 画面下部の「🧭 FIREシミュレーションを実行」ボタンを押します。
5. 表示された「4. 今月のFIRE判定」「5. 今月の推奨行動」を確認します。
6. 実際に使った金額が分かったら、「12.5. 使っていい額と実際に使った額の突き合わせ」に記録します。
7. 月次チェックリストを確認します。CSV取り込み・シミュレーション実行・実績記録は、実際にその操作をすると**自動でチェックが入ります**（ラベルに「（自動検出）」と表示されます）。NISA/iDeCoの枠の確認だけは手動でチェックしてください。チェックは表示用のメモで、計算には一切影響しません。次回起動時も保持され、月が変わっても自動では消えないので、新しい月になったら「↺ チェックをリセット」を押してください。
8. 最後に「13. 保存・履歴管理」で、今回のシミュレーションを名前を付けて保存します。

より詳しく分析したいときは、「🗂️ 簡易モード」をOFF（詳細モード）にすると、すべてのセクションが常時展開表示されます。

## 2. 入力項目リファレンス（セクション1〜3）

簡易モードでは「📝 入力・資産の確認・編集（1〜3）」を開くと、以下の3ブロックがすべて出てきます。

### 1. 資産（現金・投資・NISA・iDeCo）

**証券会社CSVで取り込む（任意）**：SBI証券の「保有ファンド一覧」CSVをアップロードすると、下記の「課税口座残高」「NISA現在残高」「NISA累計投資額・簿価」「うち成長投資枠の累計投資額」に自動反映されます。現金・iDeCoの残高、今年のNISA投資額はCSVに含まれないため、引き続き手入力が必要です。アップロードすると、保有ファンドの配分（カテゴリ別・口座種別）の評価と、AIによるバランス総評も表示されます。

**使うタイミング**：証券会社の保有資産が変わったとき（入金・売買・評価額の更新など）。手入力でも問題ありません。

| 項目 | 内容 |
|---|---|
| 現在の総金融資産（万円） | 現金・投資すべて含めた合計 |
| 現金・預金（万円） | 総金融資産のうち、現金・預金として持っている額 |
| NISA現在残高（万円） | NISA口座の評価額合計 |
| NISA累計投資額・簿価（万円） | 非課税保有限度額の判定に使う取得価額 |
| うち成長投資枠の累計投資額（万円） | NISA成長投資枠の内数 |
| 今年のNISA投資額（万円） | 今年分のNISA投資額（CSVには反映されないため常に手入力） |
| 課税口座残高（万円） | 特定口座・一般口座の評価額合計 |
| 課税口座の含み益割合（%） | 課税口座残高のうち含み益の割合の目安（売却時の税額概算に使用） |
| iDeCo現在残高（万円） | iDeCoの評価額合計 |
| iDeCo月額掛金（万円） | iDeCoへの毎月の拠出額 |
| iDeCo年間上限（万円） | iDeCoの年間拠出上限（制度改正時は要見直し） |

### 2. 収支・シミュレーション条件

**使うタイミング**：市場環境は基本的に毎回そのまま使えばOKです。自分の相場観で変えたい場合のみ手動で選び直してください。それ以外の項目は、年齢が変わったときや前提を見直したいときに更新します。

| 項目 | 内容 |
|---|---|
| 現在年齢 | あなたの現在の年齢 |
| シミュレーション終了年齢 | 資産寿命シミュレーションを何歳まで計算するか |
| 年間生活費（万円） | 1年間に使う生活費の合計 |
| 年間副収入（万円） | 年金以外の副収入（アルバイト・配当等） |
| 想定運用利回り（%） | 資産寿命シミュレーションで使う年率リターン |
| 想定インフレ率（%） | 生活費が毎年何%ずつ上がると仮定するか |
| 安全余裕率（%） | 基礎シミュレーションの推奨支出を、どれだけ余裕を見て抑えるか |
| 最低確保する現金（か月） | 通常時に最低限持っておきたい現金の月数 |
| 現在の市場環境 | 弱気相場〜深刻な暴落まで、S&P500の下落率から自動で提案されます（前回入力の自動読み込みの対象外。毎回その場で判定）。手動で変更することもできます |

### 3. 保険料・税金・将来予定

| 項目 | 内容 |
|---|---|
| 年金受給開始年齢 | 何歳から年金を受け取る想定か。早期リタイア期（60歳〜受給開始前）かどうかの判定にも使用 |
| 65歳時点の年金見込額（万円/年） | ねんきん定期便等で確認した見込額 |
| 前年の年間所得目安（万円） | 国民健康保険料・住民税の概算計算に使用 |
| 世帯人数（国保加入者数） | 国民健康保険料の概算計算に使用 |

社会保険料・住民税の金額は、**全国一律の簡易モデルによる概算**です。実際の金額はお住まいの自治体・所得状況により異なります。

**今月以降の大型支出予定**：旅行・車・医療費など、今後発生する予定の大型支出をこのブロックの下部で登録できます。金額を複数月に分散して計上することも可能です。**FIRE Compassの本来の判断（資産寿命・取り崩し）とは別の、あくまで補助的な家計管理機能**です。今後1〜数か月以内に、まとまった支出の予定があるときに使います。

**使うタイミング**：年金受給開始年齢の見直し時、前年の所得や世帯人数が変わったとき（通常は年1回程度）、大型支出の予定ができたとき。

## 3. 結果セクションのリファレンス（4〜13）

「🧭 FIREシミュレーションを実行」を押すと表示されます。簡易モードでは4・4.5・5・12.5だけが常時表示され、6〜12は「🔍 詳細分析を見る」を開くと表示されます。

| セクション | 何が分かるか | こんなときに見る |
|---|---|---|
| 4. 今月のFIRE判定 | 安全生活費・推奨生活費・上限生活費。市場環境・社会保険料・住民税の概算・悲観ケース判定などをすべて反映した、最も信頼すべき「今月いくら使っていいか」の数字。「📋 この判定の根拠を見る」でカテゴリ別に理由を確認できる | 毎月必ず確認 |
| 4.5. 今月のFIRE判定の推移 | 過去に保存した履歴から、判定結果がどう推移してきたかのグラフ | 傾向を振り返りたいとき |
| 5. 今月の推奨行動 | 目標現金・追加投資額・投資資産からの補充候補。市場環境ルールに基づく行動の提案 | 毎月確認 |
| 6. 市場環境別の防御ルール | **今の市場環境**における、目標現金・追加投資率・生活費削減率 | 今の市場環境でどのルールが適用されているか確認したいとき |
| 7. AI FIREアドバイス | 現状・リスク・今月の取り崩し方針・今月やることを、Gemini（未設定時はルールベース）が文章でまとめて説明 | 数字だけでなく文章で総合的に把握したいとき |
| 8. NISA・iDeCo・年金最適化 | NISA残り枠、iDeCo年額拠出、年金開始後の不足額など | NISA・iDeCoの使い方を最適化したいとき |
| 9. 今月の取り崩しプラン | 現金→年金→課税口座→NISA→iDeCoの順で、具体的にどこからいくら売るか、税額目安つきで提示 | 実際に売却するときの指針が欲しいとき |
| 10. 現在のFIRE状態 | 基礎シミュレーション（安全余裕率のみ反映）ベースの現状サマリー | 参考情報として |
| 11. 資産推移 | 標準・悲観・楽観ケースでの資産推移グラフ | 長期の見通しを確認したいとき |
| 12. シナリオ結果 | 各シナリオの終了時資産・最低資産・資産枯渇年齢 | 資産が尽きないか確認したいとき |
| 12.5. 使っていい額と実際に使った額の突き合わせ | 実際に使った金額を記録し、判定額との差分を確認 | 毎月、支出額が分かった後 |
| 13. 保存・履歴管理 | シミュレーションの保存・名称変更・検索・絞り込み・CSVエクスポート・削除、レポート出力（📄ボタン） | 毎月の記録用、過去の振り返り用 |

## 4. サイドバーの他ページ

左側のサイドバーから、以下のページにアクセスできます。

| ページ | 内容 | 表示条件 |
|---|---|---|
| 📊 シミュレーション比較 | 保存済み履歴を2〜4件選んで主要指標を比較 | 詳細モードのときのみ内容が表示されます（簡易モードでは案内文のみ） |
| 📋 ログ・監視 | アプリの動作イベント・エラーの記録を確認 | 同上、詳細モードのときのみ |
| 🔒 公開運用・セキュリティ | このアプリを複数人がアクセスできる形で公開運用する場合の設定確認 | 通常のローカル個人利用（非公開モード）では案内文のみ表示されます |

個人でローカル利用している場合、これら3ページは基本的に使いません。複数人向けに公開する場合や、動作履歴を詳しく調べたいときにだけ開いてください。

## 5. こんなときは、この機能

| やりたいこと | 使う機能 |
|---|---|
| 毎月の入力を楽にしたい | 何もしなくてもOK（前回入力が自動反映）。変えたい値だけ「📝 入力・資産の確認・編集」を開いて修正 |
| 証券会社の資産を反映したい | ブロック1「資産」でSBI証券のCSVをアップロード |
| 今月いくら使っていいか知りたい | セクション4「今月のFIRE判定」 |
| どこから売ればいいか知りたい | セクション9「今月の取り崩しプラン」、またはセクション7のAIアドバイス |
| 判定が厳しくなった理由を知りたい | セクション4の「📋 この判定の根拠を見る」 |
| 今の市場環境のルールを確認したい | セクション6「市場環境別の防御ルール」 |
| 大きな買い物の予定がある | ブロック3「保険料・税金・将来予定」内の大型支出予定 |
| 実際に使った金額を記録したい | セクション12.5 |
| 過去のシミュレーションと比較したい | セクション13で履歴保存→サイドバーの「📊 シミュレーション比較」（詳細モードで） |
| 結果を印刷・共有したい | セクション13の各履歴カードから「📄 レポート」ボタン |
| 何を確認すればいいか忘れがち | 画面上部の月次チェックリストを活用（一部は自動チェックされます） |

## 6. 注意事項

- 国民健康保険料・国民年金保険料・住民税の金額は、**全国一律の簡易モデルによる概算**です。実際の金額はお住まいの自治体・所得状況によって異なります。
- 取り崩しプランの税額目安も簡易的な概算であり、実際の確定申告・税額計算に代わるものではありません。
- 月次チェックリストは表示用のメモであり、FIREの判定計算には一切使用されません。一部の項目は実際の操作から自動でチェックされますが、これも判定には影響しません。
- AIアドバイス（Gemini）はAPIキー未設定時や通信エラー時、自動的にルールベースの説明文へ切り替わります。CSVアップロード時の「保有ファンドのバランス総評」も同様です。
- 「今月やること」「投資資産からの補充候補」「保有ファンドのバランス総評」等の表現はすべて参考情報であり、投資商品の売買を断定するものではありません。最終判断はご自身で行ってください。
