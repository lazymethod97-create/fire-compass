# FIRE Compass Project

## 目的
FIRE後の利用可能な生活費、資産寿命、取り崩し余力を分かりやすく可視化する。

## MVP
1. FIRE基本情報
2. 支出と副収入
3. 資産寿命シミュレーション
4. 標準・悲観・楽観シナリオ
5. 月間支出目安
6. 最低現金バッファ
7. 取り崩し・追加投資ルール

## Sprint 2ルール
- 目標現金 = 純年間支出 ÷ 12 × 最低現金月数
- 現金 > 目標現金 → 超過分を追加投資候補
- 現金 < 目標現金 → 不足分を投資資産から補充候補
- 現金 = 目標現金 → 取り崩し・追加投資は不要
- 投資資産からの補充額は、保有投資資産額を上限とする
- このルールは現金と投資資産の配分を扱い、総資産シミュレーションへ二重計上しない
