# PROJECT RULES

1. GitHubをSource of Truthとする。
2. 1 Sprint = 1主要機能。
3. 既存機能を壊さない。
4. 計算ロジックとAIの文章生成を分離する。
5. 金融判断の数値計算はPython側で行う。
6. AIは計算結果の説明・整理を担当し、勝手に数値を変更しない。
7. 新機能追加前に既存テストを実行する。
8. Sprint完了時にREADME / ROADMAP / AI_HANDOVERを更新する。
9. 手動編集で壊れやすい変更は、完成コードをまとめて提示する。
10. 実際の売買を断定する表現を避け、シミュレーションと意思決定支援として提供する。
